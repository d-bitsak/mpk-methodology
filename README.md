# Малые проектные команды (МПК)

Методология организации внутренних проектных команд, усиленных ИИ-агентами, на стыке ИТ и бизнеса.

## Онлайн-версия

[Открыть методологию](https://d-bitsak.github.io/mpk-methodology/)

Презентация содержит 24 слайда. Навигация: клавиши ←/→, пробел или кнопки в нижней части экрана.

На слайде о шаблоне брифа можно скачать заполненный синтетический пример и Skill для подготовки брифа по интервью с заказчиком.
